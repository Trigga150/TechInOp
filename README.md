# TechInOp Website

Futuristic multi-page marketing site for **Tech In Operation (TechInOp)**, featuring neon effects, subtle animations, and video/image placeholders.

## Structure

- `index.html` – Homepage with hero, product ecosystem, Innovation Lab preview, and careers teaser.
- `about.html` – Company story, mission & values, founder's message, and roadmap timeline.
- `products.html` – Detailed DAI, HAI, and RAI product sections with use cases and media.
- `innovation-lab.html` – Tech demos, AI ecosystem overview, and careers section.
- `contact.html` – Contact form, support info, investor portal, and newsletter signup.
- `assets/css/style.css` – Global styles, neon theme, layout, and animations.
- `assets/js/main.js` – Navigation toggle, scroll reveal animations, and dynamic year in footer.

Image and video files referenced in the HTML are placeholders; replace the `assets/img/*.jpg` and `assets/video/*.mp4` paths with your actual media.

## Running

Open `index.html` in a browser (or use a simple static server) to view the site. All pages are static and linked together for easy hosting on any static web host or CDN.
